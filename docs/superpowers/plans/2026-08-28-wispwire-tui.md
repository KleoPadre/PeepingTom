# План реализации WispWire: статус и очередь этапов

**Дата актуализации:** 28 августа 2026 года

**Спецификация:** `docs/superpowers/specs/2026-08-28-wispwire-tui-design.md`

## Название и границы

Единственное название приложения, Python-пакета, CLI и Homebrew-токена —
**WispWire** / `wispwire`. Этот план не меняет согласованные функциональные
требования и дизайн TUI из спецификации. Он заменяет устаревший план и
отражает только фактический прогресс и порядок дальнейшей работы.

## Правило ведения статуса

- `[x]` ставится только после появления кода, теста, требуемой проверки и
  коммита либо после ссылки на уже существующий подтверждённый коммит.
- `[ ]` означает, что результат ещё отсутствует; наличие текста в старом
  плане не является выполнением.
- Перед началом новой задачи исполнитель сверяет этот документ, целевой
  малый план и `git log`; завершённые этапы не реализуются повторно.
- Каждый новый функциональный этап получает отдельный план в
  `docs/superpowers/plans/`, проходит TDD и завершается фактическими
  проверками.
