**Цель:** добавить read-only команду `wispwire open PATH`, которая потоково
читает сводки пакетов PCAP/PCAPNG через `tshark`, выводит ограниченную таблицу
и не изменяет исходный файл.

**Архитектура:** `packets.py` содержит неизменяемую модель строки таблицы.
`tshark.py` строит команду внешнего процесса списком аргументов, читает его
stdout построчно как экранированный TSV и преобразует строки в `PacketSummary`.
`cli.py` проверяет входной путь и зависимость, передаёт лимит адаптеру и
отображает только полученные пакеты через Rich. SQLite, TUI, display filter и
поиск намеренно остаются последующими этапами.

**Стек:** Python 3.11+, Typer, Rich, стандартные `csv` и `subprocess`, pytest,
Ruff и mypy.

**Спецификация:** `docs/superpowers/specs/2026-08-28-wispwire-tui-design.md`

## Глобальные ограничения

- Поддерживать Python 3.11+, macOS Apple Silicon и Linux ARM64/x86_64.
- Все пользовательские тексты, документация и комментарии — на русском языке.
- Не использовать `shell=True`; аргументы внешних программ всегда передавать списком.
- Не запускать реальный захват и не требовать `sudo`.
- Не изменять и не удалять исходный PCAP/PCAPNG; не добавлять захваты или сетевые данные в Git.
- Не добавлять SQLite, Textual, фильтры, поиск или live-захват в этом этапе.

- [x] **Шаг 1: Написать падающие тесты команды, экранированной строки и ошибки процесса**

```python
from pathlib import Path

from wispwire.tshark import build_fields_command, parse_packet_row


def test_build_fields_command_uses_read_only_tshark_fields() -> None:
    command = build_fields_command(Path("/opt/bin/tshark"), Path("capture.pcapng"))

    assert command == [
        "/opt/bin/tshark", "-n", "-r", "capture.pcapng", "-T", "fields",
        "-E", "separator=/t", "-E", "quote=d", "-E", "escape=y", "-E", "occurrence=f",
        "-e", "frame.number", "-e", "frame.time_relative", "-e", "_ws.col.Source",
        "-e", "_ws.col.Destination", "-e", "_ws.col.Protocol", "-e", "frame.len", "-e", "_ws.col.Info",
    ]


def test_parse_packet_row_preserves_quoted_tabs_and_quotes() -> None:
    row = '"7"\t"0.250000"\t"10.0.0.1"\t"10.0.0.2"\t"DNS"\t"82"\t"Query \\"example\\"\\tname"\n'

    packet = parse_packet_row(row)

    assert packet.info == 'Query "example"\\tname'
```

а ненулевой код завершения вызывает `TsharkReadError` с `stderr` без traceback.
