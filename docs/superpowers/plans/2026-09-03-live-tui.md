# План реализации live-TUI WispWire

> **Для агентных исполнителей:** ОБЯЗАТЕЛЬНЫЙ НАВЫК: используйте superpowers:subagent-driven-development (рекомендуется) или superpowers:executing-plans для выполнения задач по очереди. Шаги отмечаются флажками (- [ ]).

**Цель:** команда wispwire capture --iface открывает безопасный live-TUI с пакетной доставкой подтверждённых пакетов, фильтрами и действиями захвата.

**Архитектура:** один фоновый LiveCaptureController владеет CaptureSession, принимает команды и кладёт неизменяемые события в очередь. LivePacketSource читает лишь закрытые сегменты, назначает кадрам сквозные номера и хранит связь с локальным номером сегмента. LiveCaptureApp дренирует события в потоке Textual; он не запускает внешние процессы и не меняет файлы.

**Технологии:** Python 3.11+, Textual, Typer, Rich, TShark, dumpcap, mergecap, SQLite FTS5 trigram, pytest, pytest-asyncio, Ruff, mypy.

**Спецификация:** docs/superpowers/specs/2026-09-03-live-tui-design.md.

## Общие ограничения

- Код, тесты, документация и сообщения пользователю пишутся по-русски; идентификаторы остаются английскими.
- Не менять поведение wispwire open и не объединять его с live-режимом.
- CaptureSession остаётся единственным владельцем dumpcap и своей сессии; все его публичные методы вызывает только поток контроллера.
- Принимать только закрытые сегменты, подтверждённые collect_closed_segments; нельзя читать .part, текущий сегмент или путь вне сессии.
- Внешние программы запускаются списками аргументов, без shell=True, sudo и сетевых вызовов. В тестах подменять dumpcap, mergecap и TShark.
- Display filter передаётся TShark через -Y без изменения. Поиск Info выполняется как регистронезависимая подстрока через SQLite FTS5 trigram.
- В UI-потоке запрещены TShark/dumpcap/mergecap, ожидание потоков и файловые операции. Он только отправляет команду и дренирует готовую очередь событий.
- Стандартные проверки: .venv/bin/python -m pytest, .venv/bin/ruff check src tests, .venv/bin/ruff format --check src tests, .venv/bin/mypy src, .venv/bin/wispwire capture --help, git diff --check.

- src/wispwire/capture.py — read-only размер подтверждённой сессии, без изменения конечного автомата.

- src/wispwire/cli.py — создаёт live-компоненты, сохраняет результат S и открывает его через существующий путь.

    def ingest(self, segments: tuple[Path, ...]) -> tuple[PacketSummary, ...]:
        added: list[PacketSummary] = []
        for segment in segments:
            if segment in self._seen_segments:
                continue
            for local in self._iter_summaries(segment, self._tshark_path, self._limit):
                global_packet = replace(local, number=self._next_number)
                self._packets[self._next_number] = LivePacket(global_packet, segment, local.number)

        self._index.append(_records_from_packets(tuple(added)))
        return tuple(added)
